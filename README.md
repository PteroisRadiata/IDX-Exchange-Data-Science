# IDX-Exchange-Data-Science
Personal public repository for IDX internship real estate project. This project creates a model and usable Streamlit app for home price prediction in California.

## Overview
The price predictor lets a user enter a single resident home address, any known property details, and see
the predicted sale price before listing. It uses investigated best features in an XGBoost model
to determine the price, and finds other comparable properties.

## Tech Stack
- Backend: Python, Jupyter Noetbooks
- Frontend: Streamlit

## Features
- User entry of home address and/or property details
- Results include: predicted price, known property details, comparable properties and location map

## Getting Started (template)
1. Clone: git clone <repo-url>
2. Backend: set DB credentials in application.properties, run the app
3. Frontend: cd client, npm install, npm start
4. Open http://localhost:3000
